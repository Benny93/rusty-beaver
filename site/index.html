RUSTY BEAVER

A DBeaver-style database tool written in Rust with GPUI, that your AI agent can drive.

SQLite, PostgreSQL and MySQL. A native, fast desktop app with a built-in MCP server: agents work the same window you look at, with no simulated mouse clicks.

Mission briefing

SQL editor

Highlighting, autocompletion of tables and columns (including after an alias like b.), and the statement under the cursor runs with one key. Scripts give one result per statement. Format, Explain and Cancel are one key away.

Edit data in the grid

Change cells, add, duplicate and delete rows, set NULL. Changes stay highlighted until you save, and then go in as one transaction, keyed on the primary key: all of them or none.

ER diagrams

Tables, keys and foreign-key links, laid out automatically. Drag the boxes around, and double-click one to open its data.

Many ways to look at a result

A sortable grid, a record form, aligned text, bar charts, and a value panel that pretty-prints JSON and shows column statistics. Search narrows the rows.

Table explorer

WHERE filters, filter by a cell's value, follow a foreign key to the referenced row, 200 rows per page with a total count, and the table's columns and DDL.

Production safety

Mark a connection as production and changes ask before they run. Read-only connections refuse them. In manual-commit mode, Commit and Rollback live in the toolbar.

Query parameters

Write :rank in the SQL, and the editor asks for the value before running it, remembering what you entered last time.

History and sessions

Every statement goes into a searchable history. Open scripts, tables and diagrams come back after a restart.

Import and export

CSV import as one transaction. Export to CSV, TSV, JSON, Markdown, plain text or INSERT statements, or copy a column as an IN (…) list.

Keeps the connection

If the database restarts, Rusty Beaver reconnects and retries the statement. Cancel stops a long query on any of the three databases.

Native and small

Built on GPUI, the GPU-accelerated UI framework behind the Zed editor. One binary per platform, dark and light themes, a splash screen, and a pixel-art beaver.

Agent-ready

54 MCP tools cover everything above. Agents read structured results and can take screenshots of what the user sees.

Built for AI agents

The running app serves MCP over streamable HTTP, on 127.0.0.1 only. Each tool is a semantic command: connect, open a table, edit a cell, run SQL. It changes what the user sees and returns structured data, so the agent and the user always look at the same thing.

Safety is built in. On production connections, an agent has to pass confirm: true before changing data. Read-only connections refuse changes outright.

# Claude Code
claude mcp add --transport http rusty-beaver http://127.0.0.1:7979/mcp
# or try it from a terminal
python3 scripts/mcp.py run_sql '{"connection": "Beaver Demo (SQLite)",
  "sql": "SELECT name FROM beavers WHERE logs_chewed > :min",
  "params": {"min": "5000"}}'

Get started

Build and run

You need a Rust toolchain, plus a few system libraries on Linux (listed in the README).

make run          # optimized build, opens the app
make dev          # debug build
make test smoke   # unit tests + an end-to-end check over MCP
make bundle       # macOS .app with icon
make help         # everything else

On first start, a demo SQLite database (beavers, lodges, missions) is created, so there's something to explore right away.

Keys to remember

Mod+EnterRun the statement at the cursor
Mod+Shift+EnterRun the whole script
Mod+.Cancel the query
Mod+Shift+FFormat SQL
F2Edit a cell
Mod+SSave the script or the grid changes
F1All shortcuts

Mod is Cmd on macOS and Ctrl on Linux and Windows.
